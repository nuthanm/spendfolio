## Mobile Responsive Behavior

- Cards stack vertically on small screens
- Tabs remain horizontal (may scroll on very small screens)
- Transaction list is full-width
- Touch-friendly buttons with adequate padding
- Form inputs expand to full width

## Color Scheme

- **Gold/Positive**: Amber/Gold theme (#FCD34D, #D97706)
- **Buy/Positive Actions**: Green (#16A34A)
- **Sell/Negative Actions**: Red (#DC2626)
- **Profit**: Green text (#16A34A)
- **Loss**: Red text (#DC2626)
- **Progress Bar**: Amber gradient
- **Backgrounds**: White/transparent with backdrop blur

## Interactive States

- **Hover**: Cards and buttons show slight background change
- **Active Tab**: Bottom border highlight in amber, text in darker ink
- **Disabled Button**: Reduced opacity, cursor not-allowed
- **Loading**: "Adding...", "Selling...", etc.
- **Error Message**: Red background box with error text

## Data Validation Feedback

- **Amount ≤ 0**: "Grams and rate must be positive"
- **Oversell**: "Cannot sell 30g. You only have 25g."
- **Missing Fields**: HTML5 required validation
- **Success**: Message at top, tab switches to overview

## Performance Optimizations

- Lazy load transaction history (initially show recent 5)
- Animated numbers use requestAnimationFrame
- Form resets after successful submission
- Optimistic UI updates (local state + server revalidation)
- Debounce rate input for calculations
